# 🐍 贪吃蛇游戏 - Snake Game

一个集成到 Claude Code Runner 项目的现代化贪吃蛇小游戏。

## 📁 文件位置

- **游戏文件**: `public/snake.html`
- **访问方式**: 在 Claude Code Runner 的主界面点击顶部的 "Snake Game" 按钮，或直接访问 `/snake.html`

## 🎮 游戏功能

### 基础功能
- **蛇的移动**: 使用方向键 (↑↓←→) 或 WASD 控制
- **吃食物**: 吃掉红色食物来增长蛇的身体和获得分数
- **避免碰撞**: 不要撞到墙壁或自己的身体

### 难度系统
游戏提供 4 个难度等级：
- **简单 (Easy)**: 速度 6，适合初学者
- **普通 (Normal)**: 速度 8，平衡的游戏体验 (默认)
- **困难 (Hard)**: 速度 12，高难度挑战
- **地狱 (Expert)**: 速度 16，极限挑战

### 游戏机制
- **基础分数**: 每吃一个食物得 10 分
- **身体奖励**: 身体增长到 3、6、9 等倍数时额外得 5 分
- **难度递增**: 随着分数增加，蛇的移动速度会自动加快
- **死亡循环**: 蛇穿过边界后会出现在对面（环形地图）

### 特色功能
- **暂停/继续**: 点击"暂停"按钮或按 P 键暂停游戏
- **最高分记录**: 使用浏览器本地存储记录历史最高分
- **游戏统计**: 显示最终分数、身体长度、游戏时长等信息
- **响应式设计**: 支持桌面和移动设备
- **视觉效果**: 动态 UI、发光效果、平滑动画

## 🕹️ 控制方式

| 功能 | 按键 |
|------|------|
| 向上移动 | ↑ 或 W |
| 向下移动 | ↓ 或 S |
| 向左移动 | ← 或 A |
| 向右移动 | → 或 D |
| 暂停/继续 | P |
| 开始游戏 | Enter (或点击按钮) |

## 🎨 游戏界面

### 主界面包含
- **实时分数显示**: 当前分数、蛇的长度、历史最高分
- **游戏难度选择**: 在游戏开始前选择难度
- **控制按钮**: 开始、暂停、重置游戏
- **游戏说明**: 详细的操作指南
- **暂停界面**: 游戏暂停时的半透明覆盖层
- **游戏结束弹窗**: 显示详细的游戏统计信息

## 🛠️ 技术实现

### 核心技术
- **HTML5 Canvas**: 用于游戏渲染
- **纯 JavaScript**: 无外部游戏库依赖
- **localStorage API**: 保存最高分记录
- **事件驱动**: 实时响应键盘输入

### 代码结构
```javascript
gameState: {
  snake: [],           // 蛇身体坐标数组
  food: {},            // 食物坐标
  direction: {},       // 当前移动方向
  nextDirection: {},   // 下一帧的移动方向
  score: 0,            // 当前分数
  highScore: 0,        // 最高分
  gameRunning: false,  // 游戏运行状态
  gamePaused: false    // 游戏暂停状态
}
```

## 🚀 使用方法

### 1. 启动游戏
```bash
# 运行 Claude Code Runner 的 Web 服务器
npm run dev
# 或
npm start
```

### 2. 访问游戏
- 打开浏览器访问 Claude Code Runner 主界面
- 点击顶部导航栏的 "Snake Game" 按钮
- 或直接访问 `http://localhost:<port>/snake.html`

### 3. 游戏流程
1. 选择想要的难度级别
2. 点击"开始游戏"或按 Enter 键
3. 使用方向键或 WASD 控制蛇的移动
4. 吃掉红色食物来增长身体和增加分数
5. 避免撞到墙壁或自己的身体
6. 游戏结束时会显示详细的统计信息

## 📊 游戏统计

游戏结束时会显示：
- **最终分数**: 这次游戏获得的总分数
- **身体长度**: 最终蛇的长度
- **游戏时长**: 从开始到结束的时间
- **最高分**: 历史最高记录（如果本次超过）

## 🔧 自定义游戏

### 修改游戏速度
在 `snake.html` 中找到 `DIFFICULTIES` 对象，调整 `speed` 值：
```javascript
const DIFFICULTIES = {
    easy: { speed: 6, color: '#90EE90' },
    normal: { speed: 8, color: '#00FF00' },
    hard: { speed: 12, color: '#FFD700' },
    expert: { speed: 16, color: '#FF6347' }
};
```

### 修改游戏网格大小
调整 `GRID_SIZE` 常量（默认 20）：
```javascript
const GRID_SIZE = 20;  // 改为其他值如 25、15 等
```

### 修改食物分数
在 `update()` 函数中调整：
```javascript
gameState.score += 10;  // 改为其他值
```

### 修改蛇的初始位置和大小
在 `gameState` 对象初始化时修改：
```javascript
snake: [{ x: 10, y: 10 }]  // 改为其他坐标
```

## 🐛 已知问题和限制

1. **移动设备**: 触摸控制暂未实现，建议使用屏幕上的虚拟键盘或外接蓝牙控制器
2. **性能**: 在非常老旧的设备上可能会有性能问题
3. **本地存储**: 最高分记录依赖 localStorage，私密浏览模式下无法保存
